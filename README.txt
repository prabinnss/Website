PRABIN PAUDEL — PROFESSIONAL PORTFOLIO

1. Open index.html in a browser to preview.
2. To add a portrait, create an assets folder and save a professional photo as assets/prabin-portrait.jpg. Until then, an elegant PP placeholder is displayed.
3. To publish, upload the files to a GitHub repository and connect it to Netlify, or drag the folder into Netlify's manual deploy area.
4. CV download button is intentionally omitted because no downloadable CV file was provided. Once available, add a button linking to assets/Prabin-Paudel-CV.pdf.
5. Review all content against Prabin's latest CV before publishing. Do not publish private phone numbers or addresses without permission.

Website is static HTML, CSS and JavaScript; no build tools required.
